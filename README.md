# Jay Mirase – Portfolio

**Live Demo:** [https://jaymiraseportfolio.netlify.app/](https://jaymiraseportfolio.netlify.app/)

## Overview  
This is the personal portfolio website of **Jay Mirase**, showcasing skills, projects, experience, and contact information. The website was built to highlight technical expertise and professional growth.

---

## Features  
- Introduction / About Me section  
- Display of key technical skills  
- Showcase of selected projects  
- Work experience and education details  
- Contact section with link to email / LinkedIn  
- Responsive design for desktop & mobile  

---

## Tech Stack  
- **Frontend:** React, Tailwind CSS (or specify if another UI framework used)  
- **Hosting / Deployment:** Netlify  
- **Version Control:** Git + GitHub  

---

## How to Run Locally  
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/jay-mirase-portfolio.git
   cd jay-mirase-portfolio

2.Install dependencies:
```bash
npm install
```
3.Start the development server:
```bash
npm start
```
4.Open http://localhost:3000

Project Structure
```bash

src/
